## このリポジトリについて

本リポジトリは、ROBOMECH 2026 チュートリアル
[**「Getting Started with Manipulation × AI：模倣学習の体験セッション」**](https://robomech.org/2026/workshop-tutorial/#xdrchallenge)
のホームページ兼教材置き場です。

題材には、産業技術総合研究所を中心に開発されているオープンソースソフトウェア
[**RoboManipBaselines**](https://github.com/isri-aist/RoboManipBaselines) [[Project Page](https://isri-aist.github.io/RoboManipBaselines-ProjectPage/)]
を用います。参加者は、データ収集、モデル学習、学習済みモデルの確認、ロボット操作への接続までの一連の流れを、Google Colab上のノートブックで追体験します。

## 参加対象

このセッションは、ロボット学習や模倣学習にこれから触れる方を主な対象にしています。

- ロボットマニピュレーションとAIの接点に興味がある方
- 模倣学習をこれから学びたい学生、若手研究者、エンジニア
- RoboManipBaselinesを実際に動かしてみたい方
- 研究室外、組織外の参加者とロボット学習について交流したい方

高度な機械学習やロボット制御の事前知識は必須ではありません。PythonとGoogle Colabの基本操作ができると、ハンズオンを進めやすくなります。

## 当日の流れ

| 時間配分 | 内容 |
| --- | --- |
| 5分 | Warm-up、アイスブレイク、自己紹介 |
| 10分 | 座学: ロボット学習の基礎、模倣学習の応用例 |
| 20分 | プログラム紹介、RoboManipBaselinesの説明、環境構築 |
| 80分 | ロボット学習体験: データ収集、モデルトレーニング、ロボット操作体験 |
| 25分 | 学習済みモデルの確認、議論 |
| 10分 | Wrap-up、成果共有、Q&A |

## Learning Path

| Step | 体験すること | 到達目標 |
| --- | --- | --- |
| 1 | Google Colabを準備 | GPUランタイムを使える状態にする |
| 2 | RoboManipBaselinesをセットアップ | ハンズオンに必要な実行環境を構築する |
| 3 | データ収集の流れを確認 | 模倣学習で使うデータの構造を理解する |
| 4 | 模倣学習モデルを学習 | 学習ジョブを実行し、出力を確認する |
| 5 | 学習済みモデルを評価 | 学習結果の見方と改善の観点を知る |
| 6 | ロボット操作への接続を議論 | 実機・シミュレーションで使う際の論点を整理する |

## 事前準備

参加前に以下を準備してください。特にGoogle Colabを利用する場合は、Googleアカウントの作成とColabの基本操作に慣れておくことを推奨します。一方で、WSLやDockerやLinux環境をお持ちの方は、ローカル環境での実行も可能です。その場合はGoogle Colabの利用は必須ではありません。

| 必要なもの | 補足 |
| --- | --- |
| Googleアカウント | Google Colabを利用する場合に必要です。 |
| ブラウザ | Google Colabを利用する場合に必要です。Google Chrome等での動作確認済み |
| 安定したネットワーク接続 | 環境構築のため、ライブラリのインストールが必要です。会場の環境によっては速度が影響する可能性があります。 |
| ノートPC | 現地参加の場合も各自のPCで作業します |

Colabのランタイム設定は、ノートブック内の指示に従ってください。GPUランタイムを利用できる場合は、T4 GPU等の利用を推奨します。

## SIマニピュレーション若手の会

[SIマニピュレーション若手の会](https://sites.google.com/view/sice-si-manipulation/Wakate) は、ロボティクスやマニピュレーションを研究課題に持つ若手研究者、エンジニア、学生を中心とした交流の場です。

技術系イベント、勉強会、実装チャレンジ、Slack等を通じて、研究室や所属組織を越えた議論とネットワーク形成を目指しています。本イベントもその活動の一環として、ロボット学習に興味を持つ初学者や若手研究者が、実装に触れながら交流できる場をつくることを目的としています。


運営委員：
- [元田智大](https://researchmap.jp/tomohiro.motoda) (産業技術総合研究所)
- [田畑研太](https://researchmap.jp/kenta_tabata) (宇都宮大学)
- [東和樹](https://researchmap.jp/higashi.kazuki) (大阪大学)
